Konfiguracja danych drogowych

Wklej klucz API TomTom. Usługa Traffic Flow udostępnia bieżące prędkości na drogach, a Routing API może uwzględniać ruch przy wyznaczaniu trasy. Klucz wpisany tutaj jest przechowywany lokalnie w tej przeglądarce. Ogranicz klucz w panelu dostawcy do dozwolonych domen i usług.

Bez klucza mapa bazowa działa, ale nie pokazuje danych live. Ta statyczna wersja nie ma własnego serwera — do publicznego wdrożenia produkcyjnego zalecany jest backend, który chroni klucz API.

Jak czytać mapę

Warstwa ruchu pokazuje prędkość na drogach, nie koloruje całych dzielnic według czasu dojazdu. Czas do konkretnego punktu jest wyliczany oddzielnie przez API tras. Nie utożsamiamy braku danych z płynnym ruchem.
Źródła: OpenStreetMap (mapa bazowa) i TomTom Traffic/Routing po skonfigurowaniu klucza. Czasy tras są estymacjami dostawcy dla chwili zapytania, a nie gwarancją. Automatyczne odświeżanie działa, gdy strona pozostaje otwarta; iOS może wstrzymywać karty w tle.
